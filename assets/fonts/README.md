# Fonts

Place **Inter** and **Montserrat** TTF files here (OFL license, with Cyrillic):

- `Inter-Bold.ttf`, `Inter-Regular.ttf`
- `Montserrat-Bold.ttf`, `Montserrat-Regular.ttf`

Download from [Google Fonts](https://fonts.google.com/).

Without these files, text overlay uses Pillow's default bitmap font.
